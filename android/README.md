# MotionShelf Android 伴侣

这是面向 Android 11 及以上版本的原生局域网传输端。它会自动广播寻找电脑端已经开启的“手机导入”会话，并使用 SHA-256 预检、4 MiB 分片、断点续传和前台数据同步服务发送原始照片、视频及 Android Motion Photo。

## 使用

1. 在 Windows 或 macOS 的 MotionShelf 中选择“导入 → 用手机扫码导入”，电脑会同时开启网页二维码和 Android 自动发现。
2. 手机与电脑连接同一 Wi-Fi，打开 Android 伴侣；发现电脑后选择照片和视频。
3. 传输可在息屏后继续。电脑完成内容校验后，手机会询问保留原件还是移到 Android 系统回收站；选择移入时会先显示 MotionShelf 的说明，再打开 Android 系统授权窗口，只有确认授权后才会执行。
4. 进入“管理已导入照片与回收站”，可以勾选部分或全部已经传到电脑的项目，再批量移入系统回收站；回收站区可以逐项或全部恢复。旧版本保存的文件选择器 URI 会在删除前尝试映射到本机 MediaStore；云端或第三方文件源不提供系统回收站接口时，应用会明确提示并保留手机原件。

## 构建

使用 Android Studio Ladybug 或更新版本打开 `android/`，安装 Android SDK 35 与 JDK 17，然后运行 `app`。发布 APK 前应配置正式应用图标、签名密钥和隐私说明。

自动发现使用 UDP 端口 `55723`；照片传输使用电脑端界面显示的临时 TCP 端口。Windows 第一次运行时需允许 MotionShelf 访问专用网络。
